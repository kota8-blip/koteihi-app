## ✅ 実装済み機能（最新状態）

### 1. ログイン機能
**ファイル**: `pages/login.vue`
- APIでユーザー認証
- Vuex storeに保存（`store/userInfo.js`）
- Cookieで永続化（ページ遷移時のみ。リロードでクリア）
- ログイン成功後 → `/userdetail` にリダイレクト

**実装パターン**:
```javascript
// ログイン処理
this.$store.dispatch("userInfo/login", user);
```

### 2. ログイン状態による条件分岐表示
**実装ページ**: `pages/order.vue`

**条件分岐ロジック**:
```vue
<!-- ログイン済み: 注文リスト表示 -->
<order-list v-if="userInfo && userInfo.mobile" />

<!-- 未ログイン: ログイン促進UI表示 -->
<div v-if="!userInfo || !userInfo.mobile" class="no-data">
  <svg class="nodata">...</svg>
  <p>ログイン後にテイクアウトの注文履歴を確認する</p>
  <button @click="$router.push('/login')">ログインしてください</button>
</div>
```

**重要ポイント**:
- `||` (OR) と `&&` (AND) の使い分けが重要
- `{}` (空オブジェクト) は truthy
- `v-if="!userInfo || !userInfo.mobile"` が正しい（ANDは誤作動する）

### 3. Vuex State管理
**ファイル**: `store/userInfo.js`

**構造**:
```javascript
export default {
  namespaced: true,  // 必須!
  state: { userInfo: {} },
  getters: {
    userInfo(state) { return state.userInfo; }
  },
  actions: {
    login({ commit }, value) {
      commit(LOGIN, value);
    }
  },
  mutations: {
    [LOGIN](state, value) {
      cookies.set('userInfo', value);
      state.userInfo = value;
    }
  }
}
```

**使い方**:
```javascript
// コンポーネント側
computed: {
  ...mapGetters("userInfo", ["userInfo"])  // モジュール名必須
}
```

### 4. Mutation定数管理
**ファイル**: `store/types.js`

```javascript
export const LOGIN = 'LOGIN'
export const OUT_LOGIN = 'OUT_LOGIN'
export const USER_INFO_UPDATA = 'USER_INFO_UPDATA'
```

**使用パターン**:
```javascript
import { LOGIN } from './types'

mutations: {
  [LOGIN](state, value) { ... }  // ブラケット記法
}
```

### 5. グローバルレイアウト設定
**ファイル**: `layouts/default.vue`

```javascript
computed: {
  ...mapGetters("userInfo", ["userInfo"])
}
```
→ 全ページでuserInfo getterを呼び出してCookie復元を実行

## 🔧 よく使うVuexパターン

### mapGettersの使い方
```javascript
// ❌ 間違い（namespacedモジュールで使えない）
...mapGetters(["userInfo"])

// ✅ 正しい
...mapGetters("userInfo", ["userInfo"])
```

### Getterは読み取り専用
```javascript
// ❌ 間違い（getterでstateを変更）
getters: {
  userInfo(state) {
    state.userInfo = cookies.get('userInfo')  // ダメ!
  }
}

// ✅ 正しい（actionで変更）
actions: {
  restoreUserInfo({ commit }) {
    const user = cookies.get('userInfo')
    commit('SET_USERINFO', user)
  }
}
```

## 🐛 解決済みバグ

### 1. `[vuex] unknown getter: userInfo`
**原因**: mapGettersでモジュール名を指定していなかった  
**解決**: `...mapGetters("userInfo", ["userInfo"])`

### 2. `[vuex] do not mutate vuex store state outside mutation handlers`
**原因**: getterでstateを直接変更していた  
**解決**: action + mutationで変更する

### 3. ログイン状態が遷移で消える
**原因**: getterが呼ばれていない  
**解決**: `layouts/default.vue` でmapGetters追加

### 4. v-if条件が誤作動
**原因**: `!userInfo && !userInfo.mobile` で空オブジェクトを考慮できていなかった  
**解決**: `!userInfo || !userInfo.mobile` に変更（OR演算子）
