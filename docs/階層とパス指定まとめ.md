# Vue/Nuxt パス指定・階層ルールまとめ

## 1. 相対パスの基本
- `./` : 現在のファイルと同じディレクトリ
- `../` : 1つ上の階層（親ディレクトリ）
- `../../` : 2つ上の階層

例：
- `import X from './foo.vue'` → 同じフォルダ内の `foo.vue`
- `import X from '../bar.vue'` → 1つ上のフォルダの `bar.vue`
- `import X from '../../baz.vue'` → 2つ上のフォルダの `baz.vue`

## 2. 階層の数え方
- 今いるファイルの場所から、目的のファイルまで「何回上に上がるか」で決まる
- 例：`pages/user/index.vue` から `components/clock.vue` へ
  - `pages/user` → `pages`（1回）→ `nuxt-elm`（2回）→ `components`（目的地）
  - → `../../components/clock.vue`

## 3. よくあるパターン
- `pages/index.vue` から `components/foo.vue` → `../components/foo.vue`
- `pages/user/index.vue` から `components/foo.vue` → `../../components/foo.vue`
- `components/bar.vue` から `assets/utils/tool.js` → `../assets/utils/tool.js`

## 4. エイリアス（Nuxtの場合）
- `~` や `@` を使うと、プロジェクトルートからの絶対パス指定ができる
- 例：`import X from '~/components/foo.vue'`

## 5. 注意点
- 階層が深くなるほど `../` の数が増える
- パスが間違うと「Module not found」エラーになる
- ファイル移動時はimportパスも必ず修正する

---

このルールを覚えておけば、どのファイルからでも正しくimportできます！
