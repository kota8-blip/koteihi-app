# 絶対パスと相対パスの違いまとめ（Vue/Nuxt向け）

## 1. 相対パスとは
- 今いるファイルの場所から見て、目的のファイルまでの「位置関係」を指定する方法
- `./` や `../` を使う
- ファイルの階層が変わるとパスも変わる

### 例
- `import X from './foo.vue'` → 同じフォルダ内
- `import X from '../bar.vue'` → 1つ上のフォルダ
- `import X from '../../baz.vue'` → 2つ上のフォルダ

## 2. 絶対パスとは
- プロジェクトのルート（最上位）からの「固定の場所」を指定する方法
- Nuxtでは `~` や `@` を使う
- ファイルの階層が変わってもパスは変わらない

### 例
- `import X from '~/components/foo.vue'` → ルート直下の `components/foo.vue`
- `import Y from '@/assets/utils/tool.js'` → ルート直下の `assets/utils/tool.js`

## 3. 使い分けのポイント
- **相対パス**：小規模・単純な構成、ファイル移動が少ない場合に便利
- **絶対パス**：大規模・階層が深い場合、どこからでも同じパスでimportできて管理が楽

## 4. 注意点
- 相対パスはファイル移動時にパス修正が必要
- 絶対パスはNuxtやWebpackの設定が必要（`~`や`@`が使えるか確認）

---

この違いを理解すれば、状況に応じて最適なパス指定ができます！
