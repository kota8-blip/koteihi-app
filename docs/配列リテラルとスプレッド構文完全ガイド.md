## 配列リテラルとは

**「配列を直接書く」方法です。`[]` で囲むと配列になります。**

### 基本形

```js
// 空の配列
const arr1 = [];

// 要素がある配列
const arr2 = [1, 2, 3];

// いろんな型が混在してもOK
const arr3 = ['りんご', 100, true, { name: '太郎' }];
```

### 重要ポイント

- `[]` で囲むと「新しい配列」が作られる
- カンマ `,` で要素を区切る
- 関数の引数として配列リテラルを使える

```js
// 関数に配列を渡す
someFunction([1, 2, 3]);

// Vuexのcommitに配列を渡す
this.$store.commit('setItems', [item1, item2, item3]);
```

## スプレッド構文とは

**「配列やオブジェクトの中身を展開（バラバラにする）」構文です。`...` で表します。**

### 基本的な使い方

```js
const arr = [1, 2, 3];

// スプレッド構文で展開
console.log(...arr);
// 結果: 1 2 3（配列ではなく、バラバラの値として展開される）

// 配列リテラルと組み合わせる
const arr2 = [...arr];
// 結果: [1, 2, 3]（新しい配列が作られる）
```

### 視覚的に理解する

```js
const fruits = ['りんご', 'みかん'];

// スプレッド構文を使わない場合
const result1 = [fruits];
// 結果: [['りんご', 'みかん']]  ← 配列の中に配列

// スプレッド構文を使う場合
const result2 = [...fruits];
// 結果: ['りんご', 'みかん']  ← 配列が展開されて並ぶ
```

## 組み合わせパターン

### パターン1: 配列のコピー

```js
const original = [1, 2, 3];
const copy = [...original];

// originalとcopyは別物（参照が違う）
copy.push(4);
console.log(original); // [1, 2, 3]
console.log(copy);     // [1, 2, 3, 4]
```

### パターン2: 末尾に要素を追加

```js
const cartItems = [
  { id: 1, name: 'りんご' },
  { id: 2, name: 'みかん' }
];

const newItem = { id: 3, name: 'バナナ' };

// 既存配列 + 新しい要素 = 新しい配列
const updated = [...cartItems, newItem];
// 結果: [
//   { id: 1, name: 'りんご' },
//   { id: 2, name: 'みかん' },
//   { id: 3, name: 'バナナ' }
// ]
```

**これがVuexでよく使われるパターンです！**

```js
this.$store.commit('SetCartItems', [...this.$store.state.cart.cartItems, res]);
//                                  ↑ 既存のカート配列を展開           ↑ 新商品を追加
```

### パターン3: 先頭に要素を追加

```js
const items = ['B', 'C'];
const updated = ['A', ...items];
// 結果: ['A', 'B', 'C']
```

### パターン4: 途中に要素を挿入

```js
const items = ['A', 'D'];
const updated = ['A', 'B', 'C', ...items.slice(1)];
// 結果: ['A', 'B', 'C', 'D']
```

### パターン5: 複数の配列を結合

```js
const arr1 = [1, 2];
const arr2 = [3, 4];
const arr3 = [5, 6];

const merged = [...arr1, ...arr2, ...arr3];
// 結果: [1, 2, 3, 4, 5, 6]
```

### パターン6: 配列の途中に要素を追加

```js
const items = [1, 2, 5, 6];
const updated = [1, 2, 3, 4, 5, 6];
// これを実現するには
const result = [...items.slice(0, 2), 3, 4, ...items.slice(2)];
// 結果: [1, 2, 3, 4, 5, 6]
```

## 実践的な使い方

### 実例1: カートに商品を追加

```js
// カートの状態（Vuex store）
const cartItems = [
  { id: 1, name: 'りんご', quantity: 2 },
  { id: 2, name: 'みかん', quantity: 3 }
];

// 新しく追加する商品
const newItem = { id: 3, name: 'バナナ', quantity: 1 };

// 既存のカート + 新商品 = 新しいカート
this.$store.commit('SetCartItems', [...cartItems, newItem]);
```

### 実例2: お気に入りリストに追加

```js
// 現在のお気に入り
const favorites = [
  { id: 10, shopName: 'A店' },
  { id: 20, shopName: 'B店' }
];

// 新しいお気に入り
const newFavorite = { id: 30, shopName: 'C店' };

// 追加
this.favorites = [...favorites, newFavorite];
// 結果: [
//   { id: 10, shopName: 'A店' },
//   { id: 20, shopName: 'B店' },
//   { id: 30, shopName: 'C店' }
// ]
```

### 実例3: 配列から要素を削除（filter + スプレッド構文は不要）

```js
// 削除はfilterで十分（スプレッド構文は不要）
const favorites = [
  { id: 10, shopName: 'A店' },
  { id: 20, shopName: 'B店' },
  { id: 30, shopName: 'C店' }
];

// id=20を削除
this.favorites = favorites.filter(f => f.id !== 20);
// 結果: [
//   { id: 10, shopName: 'A店' },
//   { id: 30, shopName: 'C店' }
// ]
```

### 実例4: 配列の特定要素を更新（map + スプレッド構文）

```js
const cartItems = [
  { id: 1, name: 'りんご', quantity: 2 },
  { id: 2, name: 'みかん', quantity: 3 }
];

// id=1の商品を更新
const updatedItem = { id: 1, name: 'りんご', quantity: 5 };

const updated = cartItems.map(item =>
  item.id === 1 ? updatedItem : item
);
// 結果: [
//   { id: 1, name: 'りんご', quantity: 5 },
//   { id: 2, name: 'みかん', quantity: 3 }
// ]
```

## よくある間違い

### ❌ 間違い1: スプレッド構文を忘れる

```js
const items = [1, 2];
const newItems = [items, 3];
// 結果: [[1, 2], 3]  ← 配列の中に配列が入ってしまう
```

### ✅ 正しい書き方

```js
const items = [1, 2];
const newItems = [...items, 3];
// 結果: [1, 2, 3]  ← 配列が展開されて正しく結合
```

---

### ❌ 間違い2: 配列リテラル `[]` を忘れる

```js
const items = [1, 2];
const newItems = ...items, 3;  // ← エラー！
```

### ✅ 正しい書き方

```js
const items = [1, 2];
const newItems = [...items, 3];  // ← 配列リテラル [] で囲む
```

---

### ❌ 間違い3: 元の配列を直接変更してしまう

```js
const items = [1, 2];
items.push(3);  // ← 元の配列が変更される（Vuexでは非推奨）
```

### ✅ 正しい書き方（イミュータブル）

```js
const items = [1, 2];
const newItems = [...items, 3];  // ← 新しい配列を作る
```

## スプレッド構文の実行イメージ

### ステップバイステップで理解する

```js
const arr1 = [1, 2];
const arr2 = [3, 4];
const result = [...arr1, ...arr2, 5];
```

### 展開の流れ

1. `...arr1` → `1, 2` に展開される
2. `...arr2` → `3, 4` に展開される
3. `[1, 2, 3, 4, 5]` という新しい配列が作られる

---

## まとめ

### 覚えるべきポイント

1. **`[]` で囲むと「配列」になる**
2. **`...` で「配列の中身を展開」できる**
3. **`[...既存配列, 新要素]` で「末尾に追加した新しい配列」を作る**
4. **元の配列は変更されない（新しい配列が作られる）**

### よく使うパターン

```js
// パターン1: 末尾に追加
const result = [...items, newItem];

// パターン2: 先頭に追加
const result = [newItem, ...items];

// パターン3: 配列を結合
const result = [...arr1, ...arr2];

// パターン4: 配列をコピー
const copy = [...original];
```

### Vuexでの典型的な使い方

```js
// カートに商品追加
this.$store.commit('SetCartItems', [...this.$store.state.cart.cartItems, newItem]);

// お気に入りに追加
this.favorites = [...this.favorites, newFavorite];
```

これらのパターンを覚えれば、実務でスムーズに書けるようになります！
