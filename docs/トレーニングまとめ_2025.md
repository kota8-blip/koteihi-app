# Nuxt2/Vue2 実装トレーニングまとめ（2025年10月版）

## 1. 取り組みの目的
- 現場で通用する「値の流れ（データフロー）」の理解・トレース力の強化
- バグ修正力・設計力の向上
- OSS教材が少ないため、自作トレーニングで実装力を鍛える

## 2. 実装課題一覧
### 1. 時計表示
- `index.vue`で現在時刻（HH:MM:SS）を表示
- `setInterval`で1秒ごとに自動更新
- `this.timer`を動的に追加し、`beforeDestroy`で`clearInterval`実装

### 2. メッセージ表示
- dataプロパティ`コメント`でおすすめメッセージを表示

### 3. 日付・曜日表示（最新課題）
- `index.vue`で現在の日付（YYYY/MM/DD）と曜日（日本語）を表示
- `getDay()`で曜日を数値→日本語配列で変換
- 1秒ごとに自動更新

## 3. 知識まとめ
- 「値の流れ」を意識した設計・トレースが本質的なプログラミング力
- バグ修正力が身につけば、未知の技術も怖くない
- CSSや関数は「値の流れ」を整理するための枝葉
- 日本ではこの本質を意識するエンジニアは2～3割程度
- 自分で書いて壊して直すトレーニングが最強
