# プロパティ（property）とは

## 定義
- オブジェクトやクラス、Vueコンポーネントなどが持つ「値」や「機能」のこと。
- JavaScriptでは、オブジェクトの各キーと値のペアがプロパティ。
- Vueでは、`data`・`props`・`computed`・`methods` などの各項目もプロパティと呼ばれる。

## 例（JavaScript）
```js
const person = {
  name: 'Taro',   // ← プロパティ
  age: 25        // ← プロパティ
};
```

## 例（Vue）
```js
data() {
  return {
    時間: '',      // ← プロパティ
    navList: [],   // ← プロパティ
    show1: 'xxx',  // ← プロパティ
  };
}
```

## Vueの主なプロパティ
- data: 状態や値を保持
- props: 親から受け取る値
- computed: 計算された値
- methods: 関数（機能）

## ポイント
- プロパティは「オブジェクトやコンポーネントが持つ値や機能」全般を指す
- 文脈によって「dataのプロパティ」「propsのプロパティ」など、どの部分かを区別する
