## filter
**条件に合う要素だけを残して新しい配列を作る**

### 基本構文
```js
const 新しい配列 = 元の配列.filter(要素 => 条件式);
```

### 使用例

#### 例1: お気に入り以外を削除
```js
const favorites = [
  { id: 1, name: 'A店' },
  { id: 2, name: 'B店' },
  { id: 3, name: 'C店' }
];

// id が 2 以外を残す（= id が 2 のものを削除）
const newFavorites = favorites.filter(f => f.id !== 2);
// 結果: [{ id: 1, name: 'A店' }, { id: 3, name: 'C店' }]
```

#### 例2: 店舗名で検索
```js
const orders = [
  { shopName: 'ラーメン太郎', price: 800 },
  { shopName: '寿司花子', price: 2000 },
  { shopName: 'ラーメン次郎', price: 900 }
];

// 店舗名に「ラーメン」が含まれるものだけ
const ramenShops = orders.filter(order => order.shopName.includes('ラーメン'));
// 結果: [{ shopName: 'ラーメン太郎', ... }, { shopName: 'ラーメン次郎', ... }]
```

#### 例3: 価格でフィルター
```js
const products = [
  { name: '商品A', price: 500 },
  { name: '商品B', price: 1500 },
  { name: '商品C', price: 800 }
];

// 1000円以下の商品だけ
const cheapProducts = products.filter(p => p.price <= 1000);
// 結果: [{ name: '商品A', ... }, { name: '商品C', ... }]
```

## map
**各要素を変換して新しい配列を作る**

### 基本構文
```js
const 新しい配列 = 元の配列.map(要素 => 変換後の値);
```

### 使用例

#### 例1: 価格だけを取り出す
```js
const products = [
  { name: '商品A', price: 500 },
  { name: '商品B', price: 1500 },
  { name: '商品C', price: 800 }
];

const prices = products.map(p => p.price);
// 結果: [500, 1500, 800]
```

#### 例2: データを更新
```js
const cartItems = [
  { id: 1, name: 'りんご', quantity: 2 },
  { id: 2, name: 'みかん', quantity: 3 }
];

// id が 1 のアイテムだけ quantity を変更
const updated = cartItems.map(item => 
  item.id === 1 ? { ...item, quantity: 5 } : item
);
// 結果: [{ id: 1, name: 'りんご', quantity: 5 }, { id: 2, name: 'みかん', quantity: 3 }]
```

#### 例3: 価格を1.1倍にする（税込計算）
```js
const prices = [100, 200, 300];
const taxIncluded = prices.map(price => price * 1.1);
// 結果: [110, 220, 330]
```

## find
**条件に合う最初の要素を1つだけ取得**

### 基本構文
```js
const 見つかった要素 = 元の配列.find(要素 => 条件式);
```

### 使用例

#### 例1: IDで注文を検索
```js
const orders = [
  { id: 1, shopName: 'A店' },
  { id: 2, shopName: 'B店' },
  { id: 3, shopName: 'C店' }
];

const order = orders.find(o => o.id === 2);
// 結果: { id: 2, shopName: 'B店' }
```

#### 例2: カート内の既存商品を検索
```js
const cartItems = [
  { name: 'りんご', quantity: 2 },
  { name: 'みかん', quantity: 3 }
];

const existingItem = cartItems.find(item => item.name === 'りんご');
// 結果: { name: 'りんご', quantity: 2 }
```

#### 例3: 見つからない場合
```js
const users = [
  { id: 1, name: '太郎' },
  { id: 2, name: '花子' }
];

const user = users.find(u => u.id === 999);
// 結果: undefined（見つからない）
```

## some
**条件に合う要素が1つでもあるか判定（true/false）**

### 基本構文
```js
const 結果 = 元の配列.some(要素 => 条件式);
```

### 使用例

#### 例1: お気に入りに含まれているか
```js
const favorites = [
  { order_id: 10, name: 'A店' },
  { order_id: 20, name: 'B店' }
];

const isFavorite = favorites.some(fav => fav.order_id === 10);
// 結果: true
```

#### 例2: カートに商品があるか
```js
const cartItems = [
  { name: 'りんご', quantity: 2 }
];

const hasItems = cartItems.some(item => item.quantity > 0);
// 結果: true
```

#### 例3: 高額商品があるか
```js
const products = [
  { price: 500 },
  { price: 1500 },
  { price: 800 }
];

const hasExpensiveItem = products.some(p => p.price > 1000);
// 結果: true（1500円の商品がある）
```

## every
**すべての要素が条件に合うか判定（true/false）**

### 基本構文
```js
const 結果 = 元の配列.every(要素 => 条件式);
```

### 使用例

#### 例1: すべての商品が在庫ありか
```js
const products = [
  { name: '商品A', inStock: true },
  { name: '商品B', inStock: true },
  { name: '商品C', inStock: false }
];

const allInStock = products.every(p => p.inStock === true);
// 結果: false（商品Cが在庫切れ）
```

#### 例2: すべて1000円以下か
```js
const prices = [500, 800, 900];
const allCheap = prices.every(price => price <= 1000);
// 結果: true
```

## forEach
**各要素を順番に処理（返り値なし）**

### 基本構文
```js
元の配列.forEach(要素 => {
  処理;
});
```

### 使用例

#### 例1: すべての注文を表示
```js
const orders = [
  { id: 1, shopName: 'A店' },
  { id: 2, shopName: 'B店' }
];

orders.forEach(order => {
  console.log(`注文ID: ${order.id}, 店名: ${order.shopName}`);
});
// 注文ID: 1, 店名: A店
// 注文ID: 2, 店名: B店
```

#### 例2: 価格を合計（※ reduceの方が適切）
```js
const prices = [100, 200, 300];
let total = 0;

prices.forEach(price => {
  total += price;
});
// total: 600
```

## reduce
**配列を1つの値にまとめる（合計、最大値など）**

### 基本構文
```js
const 結果 = 元の配列.reduce((累積値, 現在の要素) => {
  return 新しい累積値;
}, 初期値);
```

### 使用例

#### 例1: 価格の合計
```js
const cartItems = [
  { name: 'りんご', price: 100, quantity: 2 },
  { name: 'みかん', price: 50, quantity: 3 }
];

const total = cartItems.reduce((sum, item) => {
  return sum + (item.price * item.quantity);
}, 0);
// 結果: 350（100×2 + 50×3）
```

#### 例2: 配列を結合
```js
const words = ['こんにちは', '世界', '！'];
const sentence = words.reduce((acc, word) => acc + word, '');
// 結果: 'こんにちは世界！'
```

#### 例3: 最大値を見つける
```js
const numbers = [5, 10, 3, 8, 15];
const max = numbers.reduce((maxVal, num) => 
  num > maxVal ? num : maxVal
, 0);
// 結果: 15
```

## slice
**配列の一部を切り取って新しい配列を作る（元の配列は変更しない）**

### 基本構文
```js
const 新しい配列 = 元の配列.slice(開始位置, 終了位置);
```

### 使用例

#### 例1: ページネーション
```js
const orders = [
  { id: 1 }, { id: 2 }, { id: 3 },
  { id: 4 }, { id: 5 }, { id: 6 }
];

// 1ページ目（0〜2番目）
const page1 = orders.slice(0, 3);
// 結果: [{ id: 1 }, { id: 2 }, { id: 3 }]

// 2ページ目（3〜5番目）
const page2 = orders.slice(3, 6);
// 結果: [{ id: 4 }, { id: 5 }, { id: 6 }]
```

#### 例2: 最後のN件を取得
```js
const history = [1, 2, 3, 4, 5];
const lastThree = history.slice(-3);
// 結果: [3, 4, 5]
```

## sort
**配列を並び替える（元の配列を変更する）**

### 基本構文
```js
元の配列.sort((a, b) => {
  // a < b なら負の数（aが先）
  // a > b なら正の数（bが先）
  // a === b なら 0（順序変えず）
});
```

### 使用例

#### 例1: 数値の昇順
```js
const numbers = [30, 10, 50, 20];
numbers.sort((a, b) => a - b);
// 結果: [10, 20, 30, 50]
```

#### 例2: 数値の降順
```js
const numbers = [30, 10, 50, 20];
numbers.sort((a, b) => b - a);
// 結果: [50, 30, 20, 10]
```

#### 例3: 日付順
```js
const orders = [
  { date: '2025-03-01' },
  { date: '2025-01-15' },
  { date: '2025-02-20' }
];

orders.sort((a, b) => new Date(a.date) - new Date(b.date));
// 結果: 2025-01-15 → 2025-02-20 → 2025-03-01
```

#### 例4: 名前順（文字列）
```js
const users = [
  { name: '佐藤' },
  { name: '鈴木' },
  { name: '田中' }
];

users.sort((a, b) => a.name.localeCompare(b.name));
// 結果: 佐藤 → 鈴木 → 田中
```

## includes
**配列に特定の値が含まれているか（true/false）**

### 基本構文
```js
const 結果 = 元の配列.includes(検索する値);
```

### 使用例

#### 例1: IDが含まれているか
```js
const favoriteIds = [10, 20, 30];
const hasFavorite = favoriteIds.includes(20);
// 結果: true
```

#### 例2: 店舗名に特定の文字が含まれるか
```js
const shopName = 'ラーメン太郎';
const isRamen = shopName.includes('ラーメン');
// 結果: true
```

#### 例3: 権限チェック
```js
const userRoles = ['user', 'editor', 'viewer'];
const isAdmin = userRoles.includes('admin');
// 結果: false
```

## push/pop
**配列の末尾に追加/削除（元の配列を変更する）**

### 使用例

#### push: 末尾に追加
```js
const cartItems = [
  { name: 'りんご' },
  { name: 'みかん' }
];

cartItems.push({ name: 'バナナ' });
// 結果: [{ name: 'りんご' }, { name: 'みかん' }, { name: 'バナナ' }]
```

#### pop: 末尾を削除
```js
const items = ['A', 'B', 'C'];
const removed = items.pop();
// removed: 'C'
// items: ['A', 'B']
```

## shift/unshift
**配列の先頭に追加/削除（元の配列を変更する）**

### 使用例

#### unshift: 先頭に追加
```js
const items = ['B', 'C'];
items.unshift('A');
// 結果: ['A', 'B', 'C']
```

#### shift: 先頭を削除
```js
const items = ['A', 'B', 'C'];
const removed = items.shift();
// removed: 'A'
// items: ['B', 'C']
```

## まとめ：よく使うパターン

### パターン1: 削除
```js
// 特定の要素を削除
array = array.filter(item => item.id !== 削除したいID);
```

### パターン2: 更新
```js
// 特定の要素を更新
array = array.map(item => 
  item.id === 更新したいID ? { ...item, 新しい値 } : item
);
```

### パターン3: 検索して処理
```js
// 既存アイテムがあるか確認
const existing = array.find(item => item.id === 検索ID);
if (existing) {
  // 既存アイテムがある場合の処理
} else {
  // 新規追加の処理
}
```

### パターン4: 判定
```js
// お気に入りか判定
const isFavorite = favorites.some(fav => fav.order_id === item.id);
```

### パターン5: 合計計算
```js
// 価格の合計
const total = items.reduce((sum, item) => sum + item.price, 0);
```

## 重要ポイント

1. **元の配列を変更する** → `sort`, `push`, `pop`, `shift`, `unshift`
2. **新しい配列を返す** → `filter`, `map`, `slice`
3. **true/falseを返す** → `some`, `every`, `includes`
4. **1つの要素を返す** → `find`
5. **1つの値にまとめる** → `reduce`
6. **処理だけ（返り値なし）** → `forEach`
